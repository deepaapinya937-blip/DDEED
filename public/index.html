Discord วิธีตั้งค่า Discord OAuth
  1. เข้าสู่ Discord Developer Portal
  2. กด New Application ตั้งชื่อว่า DEKTHEP STORE
  3. ไปที่เมนู OAuth2 ในแถบซ้ายมือ
  4. ในช่อง Redirects ให้กด Add Redirect แล้ววาง URL:
    http://localhost:3000/auth/discord/callback
  5. คัดลอก Client ID และ Client Secret ไปใส่ในไฟล์ .env
Google วิธีตั้งค่า Google OAuth
  1. เข้าสู่ Google Cloud Console
  2. กด Create Credentials > OAuth client ID
  3. เลือก Application type เป็น Web application
  4. ในช่อง Authorized redirect URIs ให้กด Add URI แล้ววาง:
    http://localhost:3000/auth/google/callback
  5. คัดลอก Client ID และ Client Secret ไปใส่ในไฟล์ .env
